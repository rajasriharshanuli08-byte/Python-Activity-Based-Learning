Every case study is authored using **only the assigned course syllabus**:
- Computational thinking, algorithms, flowcharts, pseudocode
- Variables, data types, arithmetic & logical operators
- Conditional statements (`if`, `elif`, `else`)
- Loops (`for`, `while`)
- Strings & string operations
- Pattern generation
- Lists & 2D nested lists (matrices)
- Tuples, tuple operations, and tuple unpacking

## 📑 10 Mandatory Deliverables Included for Each Case Study
In accordance with academic evaluation criteria, each case study directory contains a dedicated `README.md` providing:
1. **Problem Statement:** Detailed real-world context and scope.
2. **Objectives:** Explicit functional goals and requirements.
3. **Assumptions:** Clear operational constraints and input models.
4. **Algorithm:** Step-by-step procedure.
5. **Flowchart:** Mermaid diagram depicting decision branches and loops.
6. **Pseudocode:** Language-independent structured logic.
7. **Python Source Code:** Fully commented `.py` implementation.
8. **Test Cases:** Input-output verification matrix testing boundary conditions.
9. **Sample Output Run:** Actual verbatim terminal execution logs.
10. **Conclusion:** Key pedagogical learnings and real-world relevance.

## 🚀 How to Run the Projects

### Running All 10 Case Studies in One Command
You can run the master test runner from the root directory:
```bash
python run_all.py
```

### Running an Individual Case Study
Navigate to any case study folder and run the respective Python script:
```bash
# Example: Case Study 01
cd Case_Study_01_University_Scholarship
python scholarship_allocation.py

# Example: Case Study 10
cd ../Case_Study_10_ATM_Banking_Simulation
python atm_simulation.py
```
